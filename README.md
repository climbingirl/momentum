# Travel

Это современный одностраничный проект, посвящённый теме путешествий, реализованный с использованием HTML, SCSS и JavaScript. Проект демонстрирует навыки работы с внешними API, созданием интерактивных компонентов и хранением пользовательских данных. Сайт адаптивен и корректно отображается на устройствах с разными размерами экранов.

## GitHub Pages

[https://climbingirl.github.io/momentum/](https://climbingirl.github.io/momentum/)

## Функциональность

- **Использование API погоды**  
  Сайт получает актуальную информацию о погоде для выбранного пользователем города через внешнее API. Пользователь вводит название города, и данные о погоде автоматически подгружаются и отображаются на странице.

- **Бесконечный адаптивный слайдер**  
  В проекте реализован бесконечный слайдер, который плавно прокручивается и адаптируется под ширину экрана. Слайдер позволяет удобно просматривать изображения и контент, связанные с путешествиями.

- **Хранение данных в localStorage**  
  Имя пользователя и выбранный город сохраняются в `localStorage`. Благодаря этому при повторном посещении сайта данные автоматически подгружаются, и пользователю не нужно вводить их заново.

- **Адаптивный дизайн**  
  Сайт корректно отображается на любых устройствах - от мобильных телефонов до десктопов.

## Технологии

- HTML5  
- SCSS  
- JavaScript (ES6+)  
- Внешнее API для получения данных о погоде
